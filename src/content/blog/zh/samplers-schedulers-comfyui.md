KSampler 节点上有两个下拉框,大多数人保持默认:`sampler_name` 和 `scheduler`。它们是工作流里控制**模型怎么把噪声去成图像**的部分 — 同样提示词、同样种子,换一个采样器出图能明显不同。搞懂这两个旋钮,就是"出图平庸"和"出图就是我想象的样子"的差别。

本文是实用参考 — 用什么、什么时候用。前提是你已经能跑通文生图工作流并读过[第一个工作流教程](/zh/blog/your-first-comfyui-workflow/)。

## 采样器和调度器到底干什么

你点 Queue Prompt 时,模型拿到一个有噪声的 latent,任务是把它清理干净。它不一步到位,而是分多步。每一步,模型预测 latent 里还剩多少噪声并去掉一部分。20 步(或你设的步数)之后,latent 干净到可以解码成图像。

两个算法控制这个过程:

- **采样器(Sampler)** — 把"噪声预测"转换成"去噪更新"用的数学。不同采样器组合模型预测的方式不同
- **调度器(Scheduler)** — 控制每一步**去多少噪声**的函数。有的开始快后期慢,有的均匀

它们一起决定:
- 每步提取多少信息
- 最终图像多平滑或多锐利
- 图像是确定性(可复现)还是随机性(每次略不同)

## 采样器家族

ComfyUI 自带约 20 个采样器,不全有用。分组看。

### Euler 家族 — 快、简、稳

| 采样器 | 什么时候用 |
|--------|-----------|
| `euler` | 又快又稳,永远好用的默认 |
| `euler_ancestral` | 每步加噪 → 多样性更高、确定性更低,适合创造性变化 |

Euler 是主力。15-20 步要可预测结果就用它。

### DPM++ 家族 — 更锐利、更精修

| 采样器 | 什么时候用 |
|--------|-----------|
| `dpmpp_2m` | SDXL 经典爱用。比 Euler 锐利。20-30 步 |
| `dpmpp_2m_sde` | 随机版。变化更多,质量同 |
| `dpmpp_3m_sde` | 高阶,复杂场景更好。慢一些 |
| `dpmpp_sde` | 原版 SDE。随机,适合颗粒感/胶片感 |

DPM++ 通常同步数下出图比 Euler 锐利。代价是稍慢。

### Heun 家族 — 高质量、慢

| 采样器 | 什么时候用 |
|--------|-----------|
| `heun` | 每步两次函数评估。质量更高,~2 倍慢 |
| `heunpp2` | 改进版 |

不在乎速度要打磨成品时挑 Heun。

### 其它有用的

| 采样器 | 什么时候用 |
|--------|-----------|
| `lms` | 线性多步。快、略软,早期实验用 |
| `lcm` | LCM-LoRA 采样(总共 4-8 步)。极快,需要加载 LCM LoRA |
| `uni_pc` | 统一预测-修正。各步数下都很稳 |

可以忽略:`ddim`、`pndm` — 老的,基本被替代了。

## 调度器列表

调度器控制噪声在各步之间的分布。

| 调度器 | 效果 |
|--------|------|
| `normal` | 默认,接近线性。永远不错 |
| `karras` | 末段步数多 → 细节更精。多数采样器搭配都好 |
| `exponential` | 开头步数多 → 大构图更干净 |
| `simple` | 最简调度。最快但保真度低 |
| `sgm_uniform` | SD 3 和 FLUX 用。这俩 base 必需 |
| `ddim_uniform` | 专给 DDIM 采样器 |

`karras` 是大多数人错过的最重要的升级。把 `normal` 换成 `karras`,采样器不变,经常无副作用就把细节提升一档。

## 推荐组合

采样器+调度器搭配比单选谁更重要。某些组合的效果远超它们各自的总和。

| 目标 | 采样器 | 调度器 | 步数 | 说明 |
|------|--------|--------|------|------|
| 默认/第一次试 | `euler` | `normal` | 20 | 永远能用 |
| **更锐利的 SDXL** | `dpmpp_2m` | `karras` | 25-30 | SDXL 最流行组合 |
| 快速迭代 | `euler` | `simple` | 15 | 调提示词时用 |
| 最大质量 | `dpmpp_3m_sde` | `karras` | 30-40 | 慢但干净 |
| 写实风 | `dpmpp_2m_sde` | `karras` | 25 | 比 Euler 少点人工感 |
| 二次元/插画 | `euler_ancestral` | `karras` | 20 | 创造性变化 |
| 胶片颗粒感 | `dpmpp_sde` | `karras` | 25 | 随机性出颗粒 |
| LCM 低步数工作流 | `lcm` | `simple` | 4-8 | 需要 LCM LoRA |
| FLUX | `euler` | `simple` 或 `sgm_uniform` | 20 | FLUX 偏好简单调度 |
| SD3 | `dpmpp_2m` | `sgm_uniform` | 28 | 必需组合 |

如果只记一件事:**SDXL 把 `euler` + `normal` 换成 `dpmpp_2m` + `karras`**。免费升级。

## 怎么自己对比

别拿菜谱当圣经。自己 A/B:

1. 选一个你用过的提示词,锁定种子(`control_after_generate: fixed`)
2. 用某采样器/调度器组合生成,保存
3. **只改采样器**,生成,保存
4. **只改调度器**,生成,保存
5. 对比三张图

差别通常很微妙。看:
- 边缘锐度(尤其头发、睫毛、布料纹理)
- 颜色饱和度
- 构图稳定性
- 伪影(颗粒、糊、平面)

"最佳"采样器看你的风格。写实和二次元想要的不一样。

## 步数交互

采样器选择和步数相互影响。

- 10 步以下:只有 LCM 和 Turbo 类采样器能用,其它看着没出完
- 15-25 步:Euler、DPM++ 2M、DPM++ 2M SDE 都好,这是日常工作甜点区
- 30-50 步:多数采样器收益递减。Heun 和 DPM++ 3M SDE 还会慢慢好。Euler 25 步以后基本不动
- 50+ 步:只对展示作品或科学复现有用,日常 20-25 够

输出看着没出完?加步数通常**不是**解药 — 换采样器更好。Euler 50 步很少比 DPM++ 2M 25 步好。

## CFG 交互

CFG(无分类器引导)控制模型对提示词的服从强度。不同采样器对高 CFG 反应不同。

- Euler: CFG ~10 内还能用,12 以上开始过饱和
- DPM++ 2M: CFG ~8 内,锐利但高 CFG 更容易"烤糊"
- DPM++ SDE: 比 DPM++ 2M 处理高 CFG(10-12)更好
- Ancestral(`_a` 后缀): 高 CFG 容易出噪点

SDXL 实用区间 CFG 5-7。SD 1.5 7-12 没问题。FLUX 用自己的 `guidance` 控件,不是 CFG。

## 随机 vs 确定性采样器

名字带 `_a`、`_sde`、`ancestral` 的采样器是**随机的** — 每步加噪。同种子 + 随机采样器 = 每次出图略有不同。

确定性采样器(Euler、不带 `_sde` 的 DPM++ 2M)同种子出**完全一样**的图。

要精确复现一张图就用确定性。想同提示词多跑几次出变化就用随机。

## 常见失败

### 输出软/糊

- 调度器不对,换 `karras`
- 步数太低
- LMS 或 simple 调度器本来就软,这是它的特性,换

### 输出过锐/烤糊

- CFG 太高,降到 6-7
- 采样器太激进(DPM++ 2M 高 CFG),试 Euler

### 同提示词同种子出不一样的图

- 你选了随机采样器(`*_sde`、`*_ancestral`)。要可复现就换确定性

### 下拉里没你要的采样器

- 一些采样器来自自定义节点包。ComfyUI 自带 ~20,ComfyUI-Manager 辅助包能加更多(`ipndm`、`lcm` 等)

### LCM 模式出噪点/质量低

- LCM 采样器需要 LCM LoRA。没装,低步数生成看着崩
- 步数严格设 4-8。多了 LCM = 伪影

## 速查表

只记这一段也行:

- **默认**:`dpmpp_2m` + `karras` + 25 步 + cfg 7
- **快速**:`euler` + `simple` + 15 步
- **最佳**:`dpmpp_3m_sde` + `karras` + 35 步
- **FLUX**:`euler` + `simple` + 20 步 + guidance 3.5
- 调优时一次只改一个变量
